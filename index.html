Fill covers from SteamGridDB in bulk

SteamGridDB doesn't accept requests from a local page, so its covers come in through this route or by pasting a cover link on a project. Export the games that have no cover, or only a Wikipedia one. Run the sgdb_covers.py helper on the exported file with your SteamGridDB key, then import the file it writes. Imported covers replace Wikipedia ones but not libretro box art or covers you set yourself.

itch.io doesn't let web pages read its devlog feeds. Port Watch's GitHub repository refreshes a copy every few hours, which is used first; this setting is only a backup for when that copy is missing. With it on, Port Watch asks rss2json.com, and allorigins.win if that fails. Both are free third-party relays that fetch the public feed for you; they see which itch.io feeds you read.

Check everything without a GitHub token?

A full check reads hundreds of repositories. Without a token, GitHub allows 60 requests an hour, so the check stops early and picks up where it left off on later checks, spread over many hours.

Release dates and new projects from Awesome Decomp Games and your feeds don't need a token and are always refreshed.
